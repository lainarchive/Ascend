# Core Loop

```text
Enter the Tower
      ↓
Choose a Path
      ↓
Face an Encounter
      ↓
Earn a Reward
      ↓
Improve Your Build
      ↓
Climb Higher
      ↓
Face a Boss
      ↓
Repeat
```

## The Run

1. Start with a simple baseline build.
2. Choose between several possible paths.
3. Complete the encounter on that floor.
4. Pick a reward or consequence.
5. Adapt the build around what was found.
6. Continue upward.
7. Reach major milestones and bosses.
8. Push as far as the run allows.

The loop should stay readable even when the underlying systems become deep.
