# Rewards

Rewards should make players think about the next few floors.

## Reward Types

- Weapons
- Abilities
- Passives
- Relics
- Currency
- Temporary buffs
- Permanent unlocks
- Cosmetics

## Reward Rules

A reward should do at least one of three things:

1. Strengthen the current plan.
2. Open a new build direction.
3. Solve an immediate problem.

The player should understand why a reward is interesting before taking it.
