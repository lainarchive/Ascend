# Core Fantasy

> **Keep climbing. Keep adapting. See what's at the top.**

Ascend is built around a simple fantasy: stepping into a tower that should not be possible, then pushing upward one floor at a time.

The player should always feel like they are discovering something new while becoming noticeably stronger.

## The Feeling

- Curiosity about what is above.
- Excitement when a build starts coming together.
- Tension when a run is close to falling apart.
- Satisfaction from turning a strange reward into a powerful combination.
- Chaos and teamwork when playing with friends.

## The Rule

The tower is the constant. The experience inside it is not.

Each run should create a different story through its rooms, rewards, events, builds, enemies, and decisions.
