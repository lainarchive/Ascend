# Builds

The build system is the heart of run-to-run variety.

## Build Pieces

- **Weapons** — define a major part of the player's attack pattern.
- **Abilities** — active tools with distinct roles.
- **Passives** — persistent effects that shape a build.
- **Relics** — unusual effects that can create synergies.
- **Run Bonuses** — temporary modifiers that disappear when the run ends.

## Synergy

Individual items should be useful on their own, but combinations should create the moments players remember.

Examples of synergy directions:

- Element + status effect
- Critical hits + attack speed
- Dodge + counterattack
- Summons + resource generation
- Low health + defensive effects

These are design directions, not final mechanics.

## Build Philosophy

A good run should eventually feel like **"this is my build"**, not simply a list of upgrades.
