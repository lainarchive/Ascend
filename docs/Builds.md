# Builds

The build system is the heart of run-to-run variety.

## No Classes or Races

Ascend does not use traditional permanent classes or races.

The player's identity is created during the run by the things they find and the systems of the map they are climbing.

> The map determines the experience. Your build is created by what happens during the run.

## Build Pieces

- **Weapons** — define how the player fights.
- **Abilities** — active tools with distinct roles.
- **Relics** — passive effects that modify the build.
- **Mutations** — rare discoveries that can fundamentally alter the build.
- **Map mechanics** — unique rules and systems that influence what can be discovered.

## Build Philosophy

Individual items should be useful on their own, but combinations should create the moments players remember.

The goal is not to stack dozens of tiny stat bonuses. Builds should create noticeable changes to combat, movement, positioning, abilities, or the player's appearance.

A good run should eventually feel like **"this is my build"**, not simply a list of upgrades.

## Garden Build Directions

These are emergent playstyles, not classes.

### Thorn

Focuses on thorns, retaliation, and damage triggered by taking hits or attacking enemies.

### Bloom

Focuses on flowers, healing, plant creation, and effects that interact with flowers.

### Root

Focuses on restricting enemy movement and controlling areas.

### Poison / Spore

Focuses on damage over time and spreading effects between enemies.

### Predator

Focuses on aggressive movement, marks, rapid kills, attack speed, and precision.

## Example Synergies

```text
Thornwhip + Vine Lash + Venom Root
→ Root / Poison control

Thornbow + Hunter's Instinct + Predator's Mark
→ Predator / precision

Ancient Growth + Bloomheart + Gardener's Gloves
→ Bloom / healing
```

The player should not need to select one of these identities at the start. The build emerges from the run.
