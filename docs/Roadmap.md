# Roadmap

Ascend is intentionally being built in small steps.

## 01 — Design

- Lock the core fantasy
- Define the first playable build system
- Define the first floor types
- Establish visual identity

## 02 — Prototype

- Player movement
- Basic combat
- One enemy
- One floor
- One reward choice
- Basic run state

## 03 — Vertical Slice

- Small playable tower section
- Multiple encounter types
- First complete build loop
- First boss
- Co-op foundation
- First-pass UI and presentation

## 04 — Alpha

- More floor variety
- More enemies
- More builds
- Events and shops
- Progression
- Saving

## 05 — Polish

- VFX
- Audio
- UI polish
- Performance
- Onboarding
- Bug fixing

## 06 — Release Prep

- Final content pass
- Testing
- Monetization review
- Analytics where useful
- Launch preparation

> Scope can change. The goal is to keep the first playable version small enough to actually finish.
