# Events

Events break up the normal combat rhythm and give the tower personality.

## Possible Events

- Travelers
- Shrines
- Sacrifices
- Gambles
- Curses
- Rescues
- Hidden rooms
- Wandering merchants
- Skill challenges

## Event Design

Events should present a choice or tradeoff whenever possible.

The best events are simple to understand but memorable because of the situation they create for the current run.
